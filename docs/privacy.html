ScrapeFlow — Privacy Policy

Last updated: March 29, 2026

Overview

ScrapeFlow is a Chrome extension for web data extraction. We are committed to protecting your privacy. This policy explains what data the extension accesses and how it is handled.

Data Collection

ScrapeFlow does not collect, store, or transmit any personal data to external servers. Specifically:

  • No browsing history is collected
  • No personal information is gathered
  • No analytics or tracking tools are used
  • No data is sold or shared with third parties

Data Processing

All data extraction and processing happens locally in your browser. The extension:

  • Reads the current page's DOM to detect and extract structured data (tables, lists, cards)
  • Uses Chrome's DevTools Protocol for full page capture
  • Stores your settings (theme, language, API key) locally using chrome.storage.local

Claude API (Optional)

If you choose to enter a Claude API key for AI-powered features, the key is stored locally on your device. When AI features are used, page content may be sent to Anthropic's API for processing. This is governed by Anthropic's Privacy Policy.

Permissions

  • activeTab — Access the current tab to extract data
  • storage — Save your preferences locally
  • scripting — Run content scripts for data extraction
  • downloads — Save exported files to your computer
  • sidePanel — Display results in the side panel
  • host_permissions (<all_urls>) — Required to extract data from any website you visit

Uninstall Feedback

When you uninstall ScrapeFlow, an optional feedback page may open. Submitting feedback is entirely voluntary. If you choose to submit, your response is stored in a private Google Sheets document accessible only to the developer.

Changes

This policy may be updated from time to time. Changes will be reflected on this page with an updated date.

Contact

If you have questions about this privacy policy, please open an issue on our GitHub repository.
